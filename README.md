# Noirdrop — 1-Click Product Generator B2B SaaS

Noirdrop is a B2B SaaS application for e-commerce store owners. It transforms raw product titles, SKU data, or manufacturer specs into high-converting e-commerce product copy in under 3 seconds using AI.

Operated by **HARTDELL LIMITED** (Company number 16021824).

---

## 🛠 Tech Stack

- **Backend:** Laravel 13, PHP 8.4
- **Frontend:** React 19 + Inertia.js
- **UI System:** Tailwind CSS v4, Lucide Icons, Magic UI glow & shimmer effects, Sonner toasts
- **Database:** SQLite / MySQL / PostgreSQL
- **AI Service:** Proprietary B2B AI Engine integration

---

## 🚀 Quick Start

1. Clone repository & install dependencies:
   ```bash
   composer install
   npm install
   ```

2. Environment configuration:
   ```bash
   cp .env.example .env
   php artisan key:generate
   ```

3. Run migrations & seed demo account:
   ```bash
   php artisan migrate --seed
   ```

4. Build frontend assets & run development server:
   ```bash
   npm run build
   php artisan serve --port=1442
   ```
